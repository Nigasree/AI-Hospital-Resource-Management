# 🏥 AI Hospital Resource Management System

An AI-powered Hospital Resource Management System that helps hospitals monitor and manage critical resources such as hospital beds, ICU units, ventilators, and medical staff. The system uses data analytics and machine learning to provide real-time monitoring and predict future resource demand, enabling faster and smarter decision-making.

---

## 📌 Overview

Hospitals often face challenges in efficiently managing resources, especially during emergencies and periods of high patient demand. This project provides a centralized dashboard that tracks resource availability and uses AI to forecast future requirements, improving hospital operations and patient care.

---

## 🚀 Features

- 🛏️ Real-time monitoring of hospital beds
- ❤️ ICU unit availability tracking
- 🌬️ Ventilator availability management
- 👨‍⚕️ Medical staff resource monitoring
- 📊 Interactive dashboard using Streamlit
- 🤖 AI-based prediction of future resource demand
- 📈 Data visualization for better decision-making
- ⚡ Faster resource allocation during emergencies

---

## ⚙️ How It Works

1. Collects hospital resource data, including:
   - Beds
   - ICU Units
   - Ventilators
   - Medical Staff
   - Patient Information

2. Processes the collected data using Python.

3. Cleans and analyzes the data with Pandas and NumPy.

4. Applies Machine Learning algorithms to identify resource usage patterns.

5. Displays real-time resource availability through an interactive Streamlit dashboard.

6. Predicts future hospital resource demand to support efficient planning.
